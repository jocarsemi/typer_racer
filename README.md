# 🏁 Type Racer

Carreras de mecanografía multijugador. Un profesor crea una sala con un texto
y los alumnos compiten escribiendo. El primero en terminar gana.

## Stack
Node.js + Express + Socket.IO (servidor) · HTML/CSS/JS vanilla (cliente).
3 ficheros de código: `server.js`, `index.html`, `package.json`.

## Local
```bash
npm install
npm start
# http://localhost:3000/#profesor   (profesor)
# http://localhost:3000/#jugador    (alumno)
